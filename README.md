## כפלי - KEFELI

אפליקציית לימוד כפל ב-React Native עם Expo, בעברית (RTL), הכוללת שלושה מצבי משחק:

- Sequential: טבלאות 2-10 בסדר קבוע, 9 שלבים
- Mixed: שאלות אקראיות, 3 דרגות קושי
- Memory: התאמת תרגילים עם אותה תוצאה, 3 דרגות

### התחלה מהירה

```bash
npm install
npm run start
```

```bash
npm install
npx expo start -c --tunnel
```

### פלטפורמות
